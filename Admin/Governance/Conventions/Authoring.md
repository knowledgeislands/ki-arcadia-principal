# Authoring

## Overview

Knowledge Islands Principal's local decisions about how it authors content within the Knowledge Islands authoring framework. The framework itself - the content layers, the activity note format, the prompt editing discipline - lives in [[Authoring Guidelines]] and applies to every island. This note records only the choices that are specific to Knowledge Islands Principal: optional sections we adopt by default, conventions we add on top of the framework, and any local divergence from the default authoring patterns.

As Knowledge Islands Principal accumulates working customs that go beyond the framework, they are recorded here. An empty Local Decisions section is itself the answer: Knowledge Islands Principal uses the framework as written.

---

## Local Decisions

None recorded. Knowledge Islands Principal currently follows [[Authoring Guidelines]] without modification.

---

## When an Entry Belongs Here

An entry belongs in this note when Knowledge Islands Principal makes a recurring authoring choice that is not implied by the framework. Examples of what would qualify if they ever became Knowledge Islands Principal practice:

- Standardising on a particular optional section in activity notes (e.g. always including Known Limitations).
- Adopting a tighter prompt-editing discipline than the framework requires (e.g. always running a dry-run before pushing).
- Codifying a local naming convention for activity prompts.

An entry does not belong here when the decision is already captured by a more specific note. Activity-specific configuration belongs under `Admin/Activities/{group}/`; routing decisions belong in [[Routing Rules]]; integration details belong in [[Admin Conventions/Integrations|Integrations]]. This note is the home for authoring practice that does not have a more specific home.
