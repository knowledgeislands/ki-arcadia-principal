# Processes

## Overview

Arcadia's governance processes - the island's realisation of the process definitions in [[Model/Processes/Processes|Processes]]. Each note here is Arcadia's specific instance of a generic KI process, carrying any island-specific configuration or membership detail. It also holds territory-wide operating processes, such as how tool releases cascade across the estate.

---

## [[Processes/Enactment Process|Enactment Process]]

Arcadia's ratification mechanism for changes to canonical knowledge. All changes that affect shared governance infrastructure - conventions, activity definitions, the constitutional layer - pass through this process before taking effect. The generic process model is defined in [[Processes/Enactment Process/Enactment Process|Enactment Process]]; this note is Arcadia's instance of it.

## [[Release Cascade]]

How a change in any Knowledge Islands tooling project is released on demand, published as a signed release, announced through the Homebrew tap and its release bot, and taken on by each consuming repository's `ki` pin and by Kris's machines. Unlike the Enactment Process, it has no generic KI model behind it: it is Arcadia's territory-wide operating picture of the release automation the tooling repositories own. It carries an Archify diagram, a table of what is automatic, manual and approved to become automatic, and what Kris does at each point.
