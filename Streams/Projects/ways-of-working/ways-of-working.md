# Ways of Working

## Outcome

Define how Kris works with agents - one master thread for project management, a small number of Project threads, detached background agents and the `ki` tools - in skills that transfer to any repository and runtime, rather than in personal preferences. The test: the thread and delegation rules live in `ki-delegation` and its sibling skills, a thread can roll up what has happened since a mark, and Kris can see the state of play across Projects and Initiatives at a glance.

This Project sits in [[knowledge-islands-model|Knowledge Islands model]].

- **Idea: notification strategy for delegated work.** One Knowledge Islands wide strategy for how the owner learns about delegated work from `ki agent` runs: `ki agent` derives an append-only events log per run (`progress`, `done`, `failed`, `blocked`, `needs-owner` and the run-level `all finished`), the thread channel is `ki agent wait --next` returning events at the coordinator's next turn, and a detached per-machine notifier (`ki agent notify`) pushes to remote channels behind one `deliver(event, destination)` adapter contract with receipts, quiet hours and duplicate suppression; Telegram is the preferred remote channel (a dedicated send-only bot, token in the macOS Keychain under the KI secret store, chezmoi carrying only the reference), Slack and a generic push service follow, platform-native notifications stay off by default, and the Observatory is a local Runs instrument over the run packets and receipts delivering over Server-Sent Events. Routing resolves owner, territory then run through a user-level `notify.toml`; messages carry summaries, identifiers and paths, never contents or secrets. Kris's decisions of 2026-10-13 in the ways-of-working run, each quoted against its tag: `HOME` '(a) keep [the strategy record] in ki-principal; hand deliveries to each repository'; `BOT-ID` (a) a dedicated send-only notifier bot; `TOKEN-HOME` (a) the macOS Keychain under the KI secret store; `QUIET` (a) `failed`, `blocked` and `needs-owner` break quiet hours while `progress` and `done` wait for the digest; `OBS-CHANNEL` (a) Server-Sent Events with browser notifications, not WebRTC; `REMOTE-SCOPE` (a) Knowledge Islands and personal territories deliver remotely by default, every other principal opts in; `ADOPT` 'adopt [the strategy record] to draft through ki-next; hand phase 1 to tools-ki and the harness now'.
