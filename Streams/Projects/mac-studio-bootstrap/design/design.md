# Design

## Overview

This folder holds the supporting notes for the [[mac-studio-bootstrap|Mac Studio bootstrap]] Project. They record working context that the Project note points to but should not carry itself. Like other design papers, they are temporary: once their content is settled in a durable home, they are deleted in one commit.

## Hosts

[[hosts|Hosts]] is the table of the estate's machines - `vega`, `sol` and `terra` - with each one's machine type and operating system. It explains that the Rig profiles and the Cheztoi host profile take their names from this table, and notes that an Omarchy move for `vega` is a separate idea belonging to the [[agent-host]] Project.
