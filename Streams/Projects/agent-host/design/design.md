# Design

## Overview

This folder holds the working papers of two design loops run for the [[agent-host|Agent host]] Project. The durability loop decided how work stays safe on the host, and its outcome is stated in [[ODR-KI-ARCADIA-001-keeping-work-safe-on-the-agent-host|ODR-KI-ARCADIA-001]]. The workstation loop shaped the host as a usable workstation, and Kris has decided it. The papers are temporary: each loop's papers are deleted in one commit once its outcome is consolidated into a Decision Record or the Project note.

## Durability

[[agent-host-durability-brief]] states the problem and the proposal. [[agent-host-durability-review-fable]] and [[agent-host-durability-review-codex]] are the independent reviews, [[agent-host-durability-report]] merges them into the durability model and rollout plan, and [[agent-host-durability-decisions]] records Kris's decisions against it.

## Workstation

[[agent-host-workstation-brief]] states how the host should become usable like Kris's own machine. [[agent-host-workstation-review-fable]] and [[agent-host-workstation-review-codex]] review it, [[agent-host-workstation-report]] merges them into one recommended design, and [[agent-host-workstation-decisions]] records Kris's decisions against it.
