# Stream Index Review Proposal

## Overview

The record also covers roadmap navigation - verifying that [[Streams]], [[Roadmap]], and the allocation ledger accurately describe the flat work records, and adding a recurring audit step to whichever maintenance activity owns structural health checks.

The goal is that by the end of the review, every index note in the Knowledge Islands pillar accurately contextualises its contents, and roadmap navigation is coherent and covered by ongoing maintenance.

---

## Governance

This stream follows the [[Philosophy/Model/Processes/Enactment Process|Enactment Process]].

---

## Approach

Work leaf-to-root within each subtree. For each index note:

1. Announce the note being reviewed
2. Read the note and assess it against the index note standard in [[Notes]]
3. Surface any decisions or options through the Cowork UI before making changes
4. Apply agreed changes
5. Move to the parent

Session boundaries are natural pause points - the review can be picked up at the next unreviewed note in the sequence.

---

## Sequence

The order follows the folder structure of `Pillars/Philosophy/`, leaf nodes first within each subtree. To be confirmed at session start by reading the current folder structure.

- [ ] Add a stream index table audit step to the appropriate maintenance activity (Health Check or Conformance Check)
